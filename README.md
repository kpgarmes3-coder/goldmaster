# Gold Master AI — ออนไลน์ใน 5 นาที
## วิธี A (เร็วสุด ~1 นาที, ไม่ต้องมีหลังบ้าน)
ลากโฟลเดอร์นี้ไปวางที่ https://app.netlify.com/drop แล้วได้ลิงก์ทันที
ผู้ใช้ใส่ Gemini API Key ของตัวเองในหน้าเว็บ
## วิธี B (ซ่อนคีย์ไว้ที่เซิร์ฟเวอร์ ~5 นาที)
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub repo ใหม่ (Add file > Upload files)
2. vercel.com > Add New Project > Import repo นั้น
3. Settings > Environment Variables: GEMINI_API_KEY = คีย์ใหม่ของคุณ > Deploy
